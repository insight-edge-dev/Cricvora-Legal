8 · Play Console Setup — Step by Step
Step-by-Step Submission Order
1

Create Google Play Developer Account

Go to play.google.com/console → Pay $25 one-time fee → Complete identity verification (may require government ID) → Wait 1-3 days for approval.

2

Create New App

Dashboard → Create app → Name: "Cricvora" → Default language: English (India) → App or game: App → Free → Accept declarations → Create app.

3

Complete App Content Section (Policy menu)

Privacy Policy URL → Ads: No → App Access: Restricted (add test account) → Content Rating: Start questionnaire → Data Safety: Fill form → Target Audience: 13+ → News App: No

4

Fill Store Listing

Title, short description, full description (copy from Section 2) → Upload feature graphic, icon, screenshots → Category: Sports → Contact email → Privacy policy URL.

5

Set Up Production Release

Production → Create new release → Upload .aab file → Release name: 1.0.0 → Release notes (copy from Section 2) → Review release.

6

Submit for Review

Resolve all warnings shown by Play Console → Start rollout to production → Wait 7-14 days for first submission review.
